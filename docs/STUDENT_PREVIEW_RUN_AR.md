# تشغيل ومعاينة رحلة الطالب

## التشغيل

من داخل مجلد المشروع:

```bash
npm install
npm start
```

ثم افتح:

```text
http://localhost:4200
```

## حساب الطالب التجريبي

```text
Email: khaled.demo@example.com
Password: 123456
```

## المسار المقترح للتجربة

1. سجّل الدخول بحساب الطالب.
2. اضغط **ابدأ درس اليوم**.
3. افتح الدرس الأول.
4. أكمل تكرارات الشادوينج المطلوبة باستخدام الميكروفون.
5. انتقل إلى الكلمات والجمل.
6. اسمع الحوار كاملًا.
7. أجب عن المراجعة السريعة.
8. راجع شاشة الإكمال ومعاينة مراجعة الغد.
9. افتح **تقدمي** و**الأسابيع** من شريط التنقل.

## ملاحظات النسخة الحالية

- إذا لم يكن Backend يعمل، يستخدم المشروع بيانات العرض المحلية كما كان يفعل قبل التعديل.
- تسجيلات الشادوينج ما زالت تستخدم المحرك الحالي وIndexedDB.
- حالة المراحل الجديدة وجدول المراجعات محفوظان محليًا في نسخة العرض فقط.
- لاختبار مستخدم جديد من الصفر، امسح بيانات الموقع لهذا العنوان من إعدادات المتصفح ثم أعد تحميل الصفحة.
